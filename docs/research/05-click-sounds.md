# 클릭 소리 조사와 결정 (2026-11-04)

## 결정 (사용자 확정)
- 1차 소리 6종: 우드블록(wood), 전자 클릭(electronic), 비프(beep), 기계식 틱(mechanical), 클라베스(clave), 카우벨(cowbell)
- 앞의 4종은 사람들이 많이 쓰는 소리라 목록 앞에 둔다. 기본값은 우드블록이다.
- 강세 박은 같은 음색에서 음을 높여 구분한다.
- 2차 후보: 림샷, 하이햇, 강세용 벨, 목소리 카운트 (녹음 샘플 필요)

## 근거 (공개된 사용 통계는 없음)
- Ableton Live: Classic(기본), Click, Wood 3종. 강세는 별도 샘플이다.
- Logic Pro: Klopfgeist 합성 클릭이고, Tone 으로 클릭부터 우드블록·클라베스까지 바꾼다. 강세는 velocity 로 구분한다.
- BOSS DB-90: 4종이다. 첫 번째가 태엽식 메트로놈 소리이고, 목소리 카운트를 포함한다.
- 포럼·리뷰: 우드블록이 장시간 연습에서 가장 덜 피곤하다는 말이 많다. 비프는 호불호가 갈리지만 시끄러운 환경에서는 선호된다.
- 확인하지 못한 것: Tempo, Pro Metronome, Soundbrenner, Piascore, Google, KORG, Wittner, Pro Tools, GarageBand, Cubase 의 기본 소리

## 합성 시작값 (근거 없는 관행값, 귀로 튜닝할 것)
| 소리 | 합성 | 보통 / 강세 | 감쇠 |
|---|---|---|---|
| wood | 사인파 + 짧은 노이즈 어택 | ~800Hz / ~1200Hz | 30~50ms 지수 감쇠 |
| electronic | 임펄스 또는 하이패스 노이즈 버스트 | 강세는 더 밝게 | 5~15ms |
| beep | 순수 사인파, 2ms 어택·릴리스 램프 | ~1000Hz / ~1500Hz | 60~80ms |
| mechanical | 400~800Hz 대역 노이즈 + 낮은 사인파 | 강세는 음을 올림 | 20~30ms |
| clave | 사인파 | ~2000Hz / ~2500Hz | ~40ms |
| cowbell | ~540Hz + ~800Hz 사인파 합 (808 방식) | 강세는 두 음을 함께 올림 | 100~150ms |

## 추가: 디지털 (2026-11-04 사용자 지정)
요청 원문: "Tempo 앱의 'Digital' 사운드와 유사한 느낌. 짧고 선명한 전자식 클릭음, 불필요한 잔향 없이 박자가 정확하게 들리도록. 첫 박의 강세음과 일반 박자음은 구분되도록, BPM 이 빨라져도 소리가 겹치거나 지연되지 않도록."
구현: 1600Hz 사인 + 3·5배음(사각파 느낌), 0.5ms 어택, 지수 감쇠 5ms, 전체 20ms. 강세는 AccentMix 로 음을 올리고(기본 세기 0.6 → ×1.3) 보통 박을 줄인다. 20ms 라 300BPM(200ms 간격)에서도 겹치지 않는다. Tempo 의 소리 파일은 쓰지 않고 직접 합성한다.
